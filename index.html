How an interface comes together

Follow the building blocks from shared design decisions to a complete product experience.

Fragmented: Teams create different styles and components, resulting in repeated work and inconsistent experiences.

Unified: Shared tokens, components, and layouts help teams build coherent experiences across products.

For teams: Designers and developers can collaborate using the same building blocks.

What they control: Colors, typography, spacing, borders, and other visual values.

Why they matter: A shared name lets teams update a decision consistently across designs and code.

Figma connection: Token values can be connected to variables in the Figma design system.

What changes: Brand colors, typography, surfaces, and other theme values.

What stays the same: Component behavior and page structure.

How it’s applied: Choose a theme for an application or page; its components use that theme’s values.

Accessibility: Check each theme against requirements such as color contrast.
